# dotaguide

Двухстраничный русскоязычный гайд по Dota 2: карта линий, пять ролей, герои и лавка предметов.

## GitHub Pages

Источник публикации: ветка main, папка /(root). Сборка не требуется.

Откройте index.html локально или опубликованный сайт.
