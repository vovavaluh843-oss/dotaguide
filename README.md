# dotaguide

Двухстраничный русскоязычный гайд по Dota 2: карта линий, пять ролей, герои и лавка предметов.

## GitHub Pages

Источник публикации: ветка main, папка /(root). Сборка не требуется.

Для локального запуска выполните `npm start` и откройте http://127.0.0.1:8765/. JavaScript использует ES-модули; прямое открытие через file:// не поддерживается. Проверки: `npm test` (Node.js 20+).

Данные и изображения: Valve / Dota 2, снимок 27.10.2026. Независимый учебный проект; не связан с Valve.

Мини-карта 7.41: игровой ресурс Valve, источник — https://liquipedia.net/commons/File:Gamemap_7.41_minimap_dota2_gameasset.png . Позиции и маршруты — учебные наложения.

## Позиции и сборки

Добавлена статистика Dota2ProTracker для всех 127 героев и 406 сборок по позициям. Снимок 27.10.2026, патч 7.41f, 7000+ MMR. Доли позиций — последние 8 дней среди матчей героя с известной ролью; популярные сборки — последние 14 дней. Данные не обновляются автоматически. Для редких ролей без достаточной выборки показывается отсутствие сборки.

## Боковая навигация

На обеих страницах есть панель с разделами «Основы», «Карта и линии», «Роли», «Герои», «Предметы», «Фишки». На широком экране она сворачивается до иконок; выбор сохраняется в браузере. На экранах до 1000 px меню открывается кнопкой в шапке, закрывается по Escape, фону или выбору раздела. Навигация поддерживает клавиатуру и подсветку текущего раздела.
